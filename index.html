Ethical generative pipeline

Generative models used as one stage in a production pipeline, not a replacement for it. You know where the training data came from, and an artist directs every step.

Agentic programming

Working with an AI agent that plans, writes, and runs code alongside you. Students learn to write the code themselves, so they can direct the agent and catch it when it's wrong.

Open-source models

Models you can download, run on your own hardware, and change. Students build their own tools on them instead of renting someone else's.
